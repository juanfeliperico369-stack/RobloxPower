# Brazaletes del Poder · Roblox Game “El Brazalete del Poder”

RPG de acción estilo cómic y anime para la comunidad de Roblox (7 a 25 años). Este repositorio contiene la **versión alterna en HTML** (un solo archivo, funciona sin internet) para auditar el diseño, la economía y la historia mientras se construye la versión de Roblox.

- **Jugar:** https://juanfeliperico369-stack.github.io/RobloxPower/
- **Archivo único:** `dist/index.html` (ábrelo en cualquier navegador, sin conexión).
- **APK Android:** pestaña *Releases* (lo genera GitHub Actions).
- **Contexto completo del proyecto:** [`docs/GUIA.md`](docs/GUIA.md) · **Historial de cambios:** [`docs/BITACORA.md`](docs/BITACORA.md)

```
npm install && node tools/build.js && node tools/check.js && node tools/sim.js && node tools/bot.js
```
